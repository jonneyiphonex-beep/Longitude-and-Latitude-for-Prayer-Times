# مواقيت الصلاة حسب خطوط الطول والعرض

إضافة Chrome لحساب الفجر والظهر والعصر والمغرب والعشاء، مع عرض الشروق، اعتمادًا على إحداثيات الموقع وطريقة الحساب المختارة. تتم الحسابات محليًا داخل الإضافة.

تُظهر الإضافة أيضًا التاريخ الهجري ومواعيد تقريبية للأيام البيض ورمضان والعيدين ويوم عرفة، إضافة إلى أسماء الشهور الهجرية وإرشادات موجزة لتنظيم الوقت والعناية بالنفس. يعتمد التحويل على تقويم أم القرى، وقد تختلف المناسبات يومًا بحسب رؤية الهلال والجهة المحلية. الإرشادات التثقيفية ليست فتوى أو نصيحة طبية أو مالية.

## البناء والتثبيت

يتطلب البناء Node.js وnpm:

```sh
npm install
npm run build
```

افتح `chrome://extensions`، فعّل «وضع المطوّر»، ثم اختر «تحميل إضافة غير مضغوطة» وحدد مجلد المشروع.

## الاستخدام

- أدخل خط العرض وخط الطول بالدرجات العشرية، أو اضغط زر تحديد الموقع واسمح للمتصفح بالوصول إليه.
- ابحث عن مدينة أو عنوان للحصول على إحداثياته من خدمة Nominatim التابعة لـ OpenStreetMap، ثم اختر أدق نتيجة مناسبة (عنوان أو مسجد/مبنى إن ظهر). OpenStreetMap يوفر الموقع الجغرافي فقط ولا يحسب مواقيت الصلاة، وقد تمثل نتيجة المدينة مركز المنطقة لا موقعًا دقيقًا. يُرسل نص البحث إلى الخدمة عند الضغط على «بحث» فقط.
- اختر طريقة الحساب المناسبة لبلدك، وحدد مذهب العصر.
- تُعرض الأوقات بالتوقيت المحلي للجهاز؛ تأكد من ضبط المنطقة الزمنية للجهاز لتطابق موقع الإحداثيات، خصوصًا عند البحث عن موقع في بلد آخر. قد تختلف النتائج بحسب الجهة المحلية المعتمدة وطريقة الحساب.
- في المناطق القطبية التي يتعذر فيها حساب الشروق أو الغروب، تُقدّر المواقيت باستخدام أقرب خط عرض صالح؛ لذا قد تكون النتائج تقريبية.

تُنسب بيانات البحث إلى [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
